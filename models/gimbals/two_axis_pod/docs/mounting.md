# 两轴安装与运动学

底座向下安装，直径 84 mm 的底部圆环水平，整机沿安装 +Z 高 91 mm。安装系采用右手坐标：+X 朝飞机前方、+Y 朝左、+Z 朝上。装配原点为圆环后端面中心；CAD 图纸 83 mm 主体段从 Z=8 mm 起算。

CAD 源坐标至安装系的转换为 `(x,y,z)=(-X,-Y,Z)`，不缩放、不镜像。球头一侧朝安装 +X。毫米至米仅在网格和质量属性导出时转换。

## 刚体与转轴

| SDF link | 包含零件 | 零位 link 原点（m） |
|---|---|---|
| `mount_link` | 圆环、一体闭合外罩、外轴轴承座 | `(0,0,0)` |
| `yaw_arm_link` | 双侧支架、两个侧盖紧固件 | `(0,0,0.056)` |
| `camera_link` | 球壳、镜框、光学窗口 | `(0.015,0,0.056)` |

yaw 采用镜头视线左负右正，外轴正方向与 CAD 原始关节正方向相反；轴线、枢轴、几何及原始零位保持一致。所有 link 的零位旋转均为单位旋转，网格已经位于对应 link 的局部坐标。外轴 `yaw_joint` 绕安装 +X，经 `(0,0,0.056) m`；内轴 `pitch_joint` 绕随动 −Y，经 `(0.015,0,0.056) m`。两轴相交于球心，因此球心不随任一轴平移。

圆环、外罩及轴承座保持固定，外轴带动支架及球头，内轴仅带动球头、镜框和光学窗口。装配固定 `mount_link`，避免将完整 model 设为 static 冻结关节。

## 机械角与光学系

`yaw ∈ [-60°,60°]`，`pitch ∈ [-80°,30°]`，采用协议 7 的 `motion_head_joint_right_positive` 定义。这是仿真采用的 CAD 已检查范围，不是实物机械止挡的测量值。`yaw/pitch` 是外轴、内轴机械角，不是飞行器 Euler 航向/俯仰角。

关节链与镜头单位视线为：

```text
R_mount_gimbal = Rx(yaw) Ry(-pitch)
los_mount = (-sin(pitch), -sin(yaw) cos(pitch), cos(yaw) cos(pitch))
```

两轴机械零位沿安装 +Z 朝天。外轴为零时，pitch=-80° 朝安装 +X 且高于水平面 10°，pitch=+30° 朝安装 −X 上方。外轴为 ±60°、内轴为 −80° 时，光轴高于安装水平面约 4.981°，水平视线相对安装 +X 为左右约 8.682°。这些角度描述光轴中心，不能直接当作画面边界；载机倾转还会改变它们相对世界水平面的值。

相机 sensor RPY 为 `(0,-π/2,0)`。sensor +X 为视线、+Y 为图像左、+Z 为图像上。零位时，视线为安装 +Z、图像右为 −Y、图像上为 −X。像素向右、向下偏移分别沿 sensor −Y、−Z。

相机 sensor 相对 `camera_link` 的位置为 `(0,0,0.0237) m`，零位安装位置 `(0.015,0,0.0797) m`，位于镜框前缘外 0.1 mm。真实入瞳未测量，该位置用于外部成像仿真。相机位置随完整机械链绕球心旋转，不随球心公转。

视线导数在图像右/下方向上的关节 Jacobian 为：

```text
J = diag(cos(pitch), -1)
```

视觉伺服使用阻尼最小二乘，零位不奇异。内轴接近 ±90° 时外轴与视线平行，外轴视线控制能力下降；当前仿真限位未达到数学奇异点。两轴不能独立保证视线方向与画面水平同时稳定。专用控制器使用上述固定光学基底，生成器和插件均拒绝不匹配的 sensor 旋转。

## 相机与近景观察

视频相机为 1920×1080、30 Hz、水平视场 60°，近裁剪 0.005 m、远裁剪 30000 m。机械实体无交叠不代表全视场无遮挡：外轴 ±60°、内轴 +30° 时，画面上缘的部分光线可在距相机约 26 mm 处碰到固定罩壳，仿真保留该真实遮挡。

浏览相机与视频相机分别配置。近景检查可从浏览近裁剪 0.005 m、鼠标灵敏度 0.1 开始；灵敏度通过 `/gui/camera/view_control/sensitivity` 服务设置，同时影响缩放、平移和旋转。滚轮参考鼠标指向的三维位置，将鼠标放在部件实体表面，使用右键缓慢拖动微调。场景定位标志与近景入口见相应场景 README。

## 动态安装

默认演示固定于 1.5 m 台面，插件 `mount_mode=upright`。机载装配通过 `mount_dynamic=true` 更新安装系相对世界的姿态，并在 TRACK 中补偿载机转动。两条轴随载机姿态变化，世界中不再总是水平。控制器的可达域、限位及跟踪约束以真实机械轴为准。
