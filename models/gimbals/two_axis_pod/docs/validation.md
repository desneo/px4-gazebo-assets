# 两轴吊舱验证

## 验证环境与范围

使用 Gazebo Harmonic（Sim 8、Transport 13、Msgs 10）、OpenCV C++、GStreamer x264 软件编码和 avdec_h264 软件解码。演示世界使用独立 `GZ_PARTITION=two_axis_validation`，吊舱固定侧装。Python 地面站验证使用仓库上一级独立环境 `two_axis_pod_venv`，其中补齐 OpenCV Python，复用系统的 Gazebo/GStreamer 绑定。

## 已通过检查

- 基本模型与演示世界通过 `gz sdf -k`。
- 三项模型测试验证实际 SDF 关节链、光学姿态、机械角边界及生成一致性。
- CTest 验证两轴运动学、图像 Jacobian、朝前退化、速度/加速度与前瞻限位、机械回零、故障锁定、CSRT 跟踪及断帧停止/丢失。
- 51 项地面站/网关离线测试覆盖协议 v3、两轴控制、拒绝滚转、seq 去重/乱序/回执、摇杆续发、释放和焦点保护。
- Gazebo 在线检查验证默认零位朝天、两路真实渲染、实际 CSRT TRACK 状态、四端限位及反向回零、单轴复位保持另一轴、手动停止续发后停车，以及朝前退化处偏航仍可机械运动。
- 地面站 UDP 在线自检收到 250 条遥测（约 49.9 Hz），home 回执、手动角速度生效和超时重新登记通过；实际图形界面运行、视频显示和两轴控制区截图检查通过。
- RTSP 软件编码/解码验证分辨率 1920×1080，5 秒检查取到 135 帧，帧序号识别成功率 100%，有效取帧阶段约 30.6 fps。

在线端点采样如下。软件端点在物理硬限位内保留 0.2° 缓冲，并提前限速；位置数值是离散采样，不表示硬限位变更。

|---|---:|---:|
| yaw 正端 | +90° | +89.687° |
| yaw 负端 | −90° | −89.677° |

复现命令见[自测说明](../tests/README.md)。运行输出与逐项结果保存于忽略入库的 `runs/two_axis_pod/`；[外观预览](preview.png)为演示世界实际渲染的零位画面。

## 限制

模型尺寸和质量是仿真近似参数，无实物尺寸或惯量标定；外观以基本几何体近似照片结构。固定安装演示不验证载机动态补偿、PX4 联动或实物控制。两轴结构不提供独立滚转稳定，pitch 接近 +90° 时外轴无法调整横向视线。在线跟踪验证使用纹理靶标，未覆盖高速目标、长时间遮挡或所有光照条件。视频结果为本机软件编解码检查，不代表网络时延或硬件编码性能保证。
