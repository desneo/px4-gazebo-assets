# 两轴立装与运动学

安装方式为人工确认的立装：直径 84 mm 的底部圆环与地面平行，导引头整体向上，整高 91 mm。安装系采用右手坐标，X 朝前，Y 朝左，Z 朝天。外轴 `yaw_joint` 绕竖直 Z，内轴 `pitch_joint` 绕随外轴转动的水平 Y。

圆环直径 84 mm、总轴向尺寸 91 mm、主体轴向尺寸 83 mm 和 6×M3 依据设计图；立装时轴向尺寸对应高度。底部厚度 8 mm 取 91−83 mm，相机球直径 48 mm 采用提供的实物尺寸。未标注的曲面、支架和孔位分布采用仿真近似。

```text
                 +Z 天空 / 两轴零位视线
                  ↑
          后部罩壳│      ↑ 镜头
             ║    │      ○ 球形相机
             ║────┼──────┤ 水平俯仰轴
            ══════╧══════╪══→ +X 前方
             水平圆环 / 安装面
             yaw：绕 +Z    pitch：绕随动 +Y
```

yaw 正方向按右手定则从 +X 前方转向 +Y 左侧。yaw ∈ [−90°, +90°]，pitch ∈ [−45°, +90°]。两轴归零时镜头朝天；yaw=0 时，pitch=+90° 朝前，pitch=−45° 朝后上方。yaw/pitch 是机械关节角，不直接等同于 PX4 FRD Euler 姿态。

活动关节链旋转为 `R_mount_gimbal = Rz(yaw) Ry(pitch)`，零位镜头朝局部 +Z。镜头单位方向为：

```text
los_mount = (cos(yaw) sin(pitch), sin(yaw) sin(pitch), cos(pitch))
```

相机 sensor RPY 为 `(π, −π/2, 0)`，sensor +X 为视线、+Y 朝图像左、+Z 朝图像上。零位对应安装系：视线 +Z，图像右 +Y，图像上 +X。像素向右/向下偏移分别沿 sensor −Y/−Z。

pitch=0° 时视线方向与 yaw 轴平行，转动 yaw 不改变镜头朝天方向，视觉伺服的方向 Jacobian 退化。球心随支架移动，画面方向随偏航旋转。手动机械轴控制和回零仍有效。俯仰离开零位后，yaw 可以调整视线方位。两轴结构没有第三轴提供画面水平稳定。

模型原点位于底部圆环的安装面中心，+Z 为圆环法线。底部圆面厚 8 mm，其上主体高 83 mm，整高 91 mm。固定底部 `mount_link` 后，罩壳、圆环上部和俯仰支架整体随 `yaw_arm_link` 绕 +Z 偏航；48 mm 相机球在支架内绕水平俯仰轴转动。零位球心在安装系 `(0.015, 0, 0.056) m`，偏航时球心随支架绕 Z 轴转动。安装到载机或支架时，以固定关节连接 `mount_link`，按实际装配设置模型 pose。专用插件模式为 `upright`。标准演示将底部圆环固定在 1.5 m 高的台面上，默认使用固定安装参考。

机载装配可在插件 SDF 设置 `mount_dynamic=true`，启用实际安装姿态更新及 TRACK 模式中的载机转动补偿。此时 +Z、+Y 等机械轴描述的是安装系；载机倾转后不再分别等于世界竖直、水平方向。机械限位、零位和朝安装 +Z 的视线退化保持不变；两轴不能保证任意载机姿态下的方向可达。
