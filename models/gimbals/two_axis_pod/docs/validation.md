# 两轴运动头验证

## 当前资产与参数

模型使用 `cad/motion_head.step` 及其关节边车，源 SHA-256 为 `d58dd5aff5154740d314d24aa36bb3deb738a3f31057635ef1b14ee6e425f628`。九个实体按固定结构、外轴支架和内轴球头分组导出为米制 DAE，源和网格校验值保存在 `cad/properties.json`。

安装为圆环水平、底座向下，球头侧朝安装 +X。外轴 +X、内轴随动 −Y，机械链 `Rx(yaw) Ry(-pitch)`，限位分别 ±60°、−80°～+30°，两轴零位光轴沿安装 +Z。协议为 7 / `motion_head_joint_right_positive`。

总质量 0.24 kg，九个已建模实体采用统一有效密度估计。固定结构、外轴支架和内轴球头质量分别约 0.174258、0.028248、0.037495 kg；重心及完整惯量由 CAD 实体积分。该质量分配、内部结构和真实入瞳未经实物标定。

## 当前左右方向检查

当前 yaw 按镜头视线左负右正；外轴正方向与 CAD 原始角相反，轴线、几何、零位和 ±60° 范围保持一致。pitch 保持 −80°～+30°，两轴机械转速保持 ±20°/s，默认真实时间频率保持 50 Hz。

基础模型 11/11、C++ CMake 构建及 CTest 2/2、装配 38/38、火箭机地理场景 59/59、固定吊舱场景 2/2 通过。控制器含实际 CSRT 左右目标、有限差分 Jacobian、载机补偿与全模式限速检查。地面站与网关共 152 项测试，无错误；仍有 29 个艾晟旧倍率断言失败记录，与修改前基线逐条一致，无新增失败。

独立无渲染 Gazebo 物理世界使用生产鼠标映射：右拖得到 yaw +14.387°、+20°/s，左拖得到 -14.442°、-20°/s；SceneBroadcaster 提供的实际 camera_link 姿态与遥测光轴一致，本机真实 UDP 收到的艾晟角度和角速度同号。旧 yaw=-X 模型配新插件时被明确拒绝。入口见 [yaw 方向检查](../tests/check_yaw_direction.py)，结果和源指纹见 [左右方向报告](../tests/results/yaw_direction.json)。

独立小型演示世界真实渲染和 CSRT 检查通过：两路 RGB 相机、7 组实际光学姿态、四个机械端点、回零、单轴复位保持另一轴和无续发看门狗停车。实测 yaw 停点 +59.797°/−59.796°、pitch −79.798°/+29.793°，符合 0.2° 软件缓冲；记录见 [当前组件在线报告](../tests/results/yaw_component_validation.json.gz)。

协议为 v7 / `motion_head_joint_right_positive`，插件、网关与 Linux/Windows 地面站须配套。当前配置尚未完成整机飞行、机载快速目标跟踪及完整 RTSP 链路复验。

## 机械速度限幅验证

当前 yaw/pitch 机械速度上限均为 ±20°/s，加速度保持 160°/s²，位置范围保持 ±60°及 −80°～+30°。该次参数、原生模型和演示世界两关节物理速度上限一致，动态装配继承检查 10/10 通过。C++ 各模式、载机补偿叠加及运行中收紧测试通过；配置不能突破 20 的上限。

独立 Gazebo 物理世界使用旧场景的 `max_rate_dps=100` 请求，插件明确告警并限制为 20。手动正反转、回零、yaw/pitch 单轴复位和由合成纹理图像驱动的实际 CSRT 跟踪共 642 个唯一姿态采样，最终指令、原始实测轴速度及艾晟转换字段峰值均不超过 20°/s；另以机械位置差分独立核对速度。yaw 单轴复位时另一轴漂移为 0°。该测试不加载视频渲染或真实目标运动，不能当作整机飞行或快速机载目标跟踪验收。

艾晟限幅 9/9、摇杆输入 19/19、基础模型 10/10 测试通过。非法/非有限/超 float32 的值仍拒绝，不将其变为边界；合法角速度在 JSON 输出端对称限幅，原始遥测与其余七字段保持原值。记录与源指纹见[机械速度限幅报告](../tests/results/mechanical_rate_limit.json)。修改后需重启 Gazebo 插件和地面站；当前 ±20°/s 配置尚未复验整机飞行和快速目标跟踪。

## 遥测频率与界面验证

默认配置通过模型资源路径直接加载 `hz=50`，在实时因子约 0.800 的独立 Gazebo 世界中测得 50.005 Hz；界面实际接收与艾晟发送均为 50.0 Hz，271 个采样时间戳全部唯一，回环接收 271 包。暂停后两项 Hz 均归零、恢复后均为 50.0，见[默认频率验证](../tests/results/telemetry_default_rate.json)。下表为多种显式配置的性能记录，100 Hz 作为可配置频率保留验证。

`controller/service/telemetry.json` 的 `hz` 同时定义插件姿态生成和网关逐份转发的真实时间目标，默认 50。使用 `steady_clock` 调度，新物理状态才可发布；`ts_mono` 仍保留仿真采样时间语义。独立 Gazebo 分区使用真实插件、网关、地面站接收/转发类和 UDP，物理步长 4 ms、不启动视频，初连后剔除首秒预热后测量：

| 配置 Hz | 设定实时因子 | 实际实时因子 | 真实时间实测 Hz | 界面接收 / 艾晟发送 Hz |
|---:|---:|---:|---:|---:|
| 100 | 0.5 | 0.500 | 99.96 | 100.0 / 100.0 |
| 100 | 0.8 | 0.800 | 100.01 | 100.0 / 100.0 |
| 100 | 1.5 | 1.467 | 97.96 | 100.0 / 100.0 |
| 50 | 0.5 | 0.500 | 49.95 | 50.0 / 50.0 |
| 100 | 0.2 | 0.200 | 50.00 | 50.0 / 50.0 |

实时因子 0.2 时物理更新只有约 50 Hz，插件记录限频告警，界面如实显示约 50 Hz，不补发重复状态。各组姿态时间戳均唯一。世界控制服务暂停后无周期遥测重发，接收/发送 Hz 在两秒窗口内归零，ping 正常；恢复后 Hz 与新姿态转发恢复。实际调度抖动或物理长步仍可能使观察窗口均值低于配置目标，不能将配置值当作实测速率。

LAN 组使用实时因子 0.8，通过 `192.168.1.100:19551` 验证完整链路：稳定窗口远端约 100.01 Hz，含暂停前后全部 858 个发送报文远端均收到，内容和顺序一致，转发丢弃与远端 socket 丢包均为 0。测试使用并行诊断客户端，未改动已有 GUI 窗口或其目标地址，不将该结果等同于已有 GUI 进程的内部统计。源指纹和测量数据见[频率报告](../tests/results/telemetry_rate.json)与[LAN 链路报告](../tests/results/telemetry_path_diagnostic.json)。

地面站底部显示目标、实际接收及艾晟发送 Hz，按最近两秒单调真实时间统计；前 0.25 秒显示预热。接收只计已确认身份的有效协议 6 姿态，发送只计成功交给本机 UDP socket 的报文。停止转发立即显示 0，断流自然衰减至 0。实际 `_draw_forward_panel` 的标准宽度、窄窗口、预热及停止画布均已检查；该检查验证绘制布局，不声明真实视频或飞行验收。修改后需同时重启 Gazebo 插件、网关和地面站。

## 地理部件视觉与移动跟踪

完整地理背景的独立两轴场景通过3个飞机目标检测及自动锁定，源夹具朝向保持不变。该次采样输入28.32 fps、视觉输出23.54 fps、推理20.362 ms；自动锁定轨迹3进入CSRT TRACK。独立端口的NVENC推流、NVDEC实际解码和Station协议6自检通过；Station收到191条遥测，约47.6 Hz、错误0。速率是该运行窗口的实际测量，不代表固定性能保证。

移动测试覆盖前进、倒退、转弯和反向转弯，共40.000仿真秒、实际位移19.952 m、3032条遥测，TRACK比例100%，中心误差P95为0.163°、独立目标真值误差P95为0.371736°、目标高度变化0。两轮约2秒实体遮挡均经历TEMP_LOST→TRACK，恢复后持续稳定，无终止LOST。

## 几何与视场限制

`gz sdf --check`通过。导入器检查九个 STEP 叶实体均有效、单实体且正体积。原始 CAD 范围检查保存在外部源工程，覆盖连续保守包络和 1° 步进组合；组件内保持同一精确实体、轴线和已检查范围。网格线性离散精度 0.035 mm、角度精度 0.12 rad，离线检查各实体网格闭合有向体积与精确体积误差不超过 3%，包络误差不超过 0.07 mm。

60°水平视场、16:9画幅的上缘采样射线，在外轴 ±60°、内轴 +30° 时碰到固定罩壳。视频近裁剪 0.005 m 保留约26 mm距离处的真实遮挡。检查只证明所采样射线，不代表已穷尽每个像素、机械角组合及实际镜头畸变。

两轴不提供独立的画面水平稳定。底座水平时当前限位内光轴中心最低仰角约4.981°；载机倾转会改变世界可达域。视频要求 NVIDIA NVENC/NVDEC，Windows D3D11 实窗和目标显卡驱动需在相应平台验证。
