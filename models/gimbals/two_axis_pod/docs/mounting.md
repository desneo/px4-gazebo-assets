# 两轴侧装与运动学

安装方式为人工确认的侧装，安装板竖直。安装系采用右手坐标：X 从安装板向外（参考前向），Y 朝左，Z 朝天。外轴 `yaw_joint` 绕 X，内轴 `pitch_joint` 绕随外轴转动的局部 Y。

```text
                 +Z 天空 / 两轴零位视线
                  ↑
        竖直安装板 │       球形相机
          ║       │          ○
          ║──────外轴────────┤ → +X 板外 / 参考前向
          ║   yaw：绕 +X    内轴 pitch：绕随动 +Y
```

从吊舱看向安装板，yaw 正方向为顺时针。yaw ∈ [−90°, +90°]，pitch ∈ [−45°, +90°]。两轴归零镜头朝天；yaw=0 时，pitch=+90° 朝前，pitch=−45° 朝后上方。偏航不是地理航向或 PX4 公共 Euler yaw。

相机链旋转为 `R_mount_camera = Rx(yaw) Ry(pitch)`，零位相机视线为局部 +Z。镜头单位方向为：

```text
los_mount = (sin(pitch), -sin(yaw) cos(pitch), cos(yaw) cos(pitch))
```

相机 sensor RPY 为 `(π, −π/2, 0)`，sensor +X 为视线、+Y 朝图像左、+Z 朝图像上。零位对应安装系：视线 +Z，图像右 +Y，图像上 +X。像素向右/向下偏移分别沿 sensor −Y/−Z。

pitch=+90° 时，视线为 +X，与 yaw 轴平行。此时转动 yaw 改变画面朝向，不改变镜头视线；视觉伺服的视线 Jacobian 退化。手动机械轴控制和回零仍有效，跟踪无法要求该轴完成不可达的横向视线调整。没有第三轴提供画面水平稳定。

基本模型的安装板在模型 YZ 平面，朝外法线为 +X。安装到载机时，以固定关节连接 `mount_link`，按实际装配设置模型 pose。模型与插件不支持通过三轴 `skyward/downward` 模式切换；专用插件模式为 `side`。标准演示安装高度 1.5 m，无动态载机姿态补偿。
