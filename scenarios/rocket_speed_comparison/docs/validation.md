# 当前配置速度对照状态

当前单机和顶部两轴吊舱组合体总高均为590 mm，总质量分别为7.70 kg和7.94 kg。组合体完整继承当前原生基础机的质量、重心、惯性、动力及电机位姿，另加0.24 kg吊舱；截短的顶部外形和碰撞不扣减基础机质量。

当前配置尚未重新完成本场景的最高稳定平飞速度对照，不能给出当前单机与组合体的稳定速度差值或通过结论。基础单机的悬停、200 km/h连续30 s巡航和300 km/h连续10 s冲刺已通过独立组件世界自验证，见[基础验证说明](../../../models/vehicles/rocket_racing_quad/docs/validation.md)；该结果不替代本场景80 m高度、95 m/s指令下连续10 s稳定窗口的专用比较。

## 当前判定范围

复测仍采用无风完整地理世界、80 m相对起飞高度及相同场景飞行设置。最高稳定窗口需连续至少10 s满足高度误差≤2 m、水平速度标准差≤0.5 m/s、范围≤2 m/s、拟合与首尾加速度绝对值≤0.2 m/s²、真值采样间隔≤0.15 s。速度与时间来自Gazebo世界位姿和仿真时间，PX4估计用于实际闭环控制。

瞬态峰值不能替代稳定窗口。达到95 m/s控制上限的设定容差时只能说明受当前控制限速约束，不能称为动力极限。比较通过还需两次运行均正常减速、落地和停机，角色、环境、设置与源资产指纹必须对应实际运行。

组合体仍采用基础机的简化阻力系数0.73、参考面积0.0177 m²和转子阻力参数，没有独立建模吊舱额外气动阻力、电池衰减、风场或随速度变化的桨效率；仿真对照不能证明真实硬件安装吊舱后没有速度损失。本场景不启动地面站、视频网关或目标跟踪，飞行结果不代表高速图像跟踪通过。

启动、停止、原始证据及报告生成命令见[场景说明](../README.md)。只有当前实际运行完成并核对报告与源资产指纹后，才可发布新的当前配置速度结论。
