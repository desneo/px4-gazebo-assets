# 单目标跟踪置信度评估

## 当前输出

两轴控制器默认使用 `sim_truth`，显式 `tracking_backend=csrt` 时使用系统 OpenCV 4.6.0，并复用三轴目录中的 CSRT/模板重捕获实现。两种后端都只输出有效状态和目标框，没有连续置信度。艾晟 `tracking_confidence` 的 25.5/0.0 是有效性约定，不是正确跟踪概率或已标定的质量分。

CSRT 公开接口只有初始化、布尔更新结果和目标框等功能，不提供相关响应图或连续分数。OpenCV 4.6.0 的 `psr_threshold` 实际与相关响应的最大值比较，不能仅凭参数名称将其称为标准峰旁比 PSR。依据：[公共接口](https://docs.opencv.org/4.13.0/d2/da2/classcv_1_1TrackerCSRT.html)、[4.6.0 实现](https://github.com/opencv/opencv_contrib/blob/4.6.0/modules/tracking/src/trackerCSRT.cpp#L379-L388)。

当前模板重捕获使用 `TM_CCOEFF_NORMED` 相似度及阈值筛选，但该分数只在重捕获时产生，不代表正常 CSRT 更新的置信度。检测模型的类别分数也不能代替锁定后的跟踪质量；飞机交叉时，同类目标都可能具有高检测分。

## 可选方案

| 方案 | 价值 | 代价与边界 |
|---|---|---|
| 修改 CSRT，导出响应峰和 PSR | 直接观察跟踪响应 | 需要维护 OpenCV 补丁或独立实现，不能只修改现有调用 |
| 小区域外观一致性 | 不更换跟踪器，可限制计算量 | 光照、姿态变化会降低相似度，相似背景可能产生高分 |
| 外观与运动、尺度、纹理、边界指标融合 | 更容易发现跳框和漂移 | 需要真实标注样本标定；运动异常应在框裁剪和平滑之前计算 |
| 异步低频 YOLO 复核 | 飞机自动锁定时检验类别及位置一致性 | 手动框选非飞机不适用，检测漏检不能直接判丢失；需要测量 CPU 争用 |
| 更换带分数的神经跟踪器 | 可获得模型自身评分 | 需要额外模型、部署依赖、遮挡与性能回归，分数仍不等于概率 |

## 推荐边界

若显式使用 CSRT，可在两轴侧增加独立的“跟踪质量”评估：初始化锚模板加受质量门限保护的自适应模板，结合原始框位移、尺度和图像边界指标。先只输出诊断指标，不改变已有控制、状态判定和重捕获行为。小 ROI 使用固定像素预算；是否满足实时要求须实测，不能仅凭 NVENC/NVDEC 正常推断。

飞机自动锁定可另行评估 2～5 Hz 的异步检测复核，使用最新帧单槽队列，保存复核帧号和结果年龄，不阻塞图像/控制，也不自动切换至其他飞机。此能力当前未实现。

评分标定需覆盖无遮挡、部分/完全遮挡、尺度/姿态/光照变化、同类交叉、快速转动、边界与低纹理天空。用标注框 IoU 和中心误差定义正确性，统计误高分率、丢失发现延迟及端到端 P95 时延，再确定评分到 0～255 的映射。未标定的输出应称为质量分，不宣称概率。

共享跟踪器属于三轴组件，直接修改会影响三轴。后续实现优先放在两轴封装内；若需要修改共享接口，应单独确认三轴影响范围。
