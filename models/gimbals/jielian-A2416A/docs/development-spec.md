# 捷联式导引头 A2416A 开发规格

## 1. 适用范围

本规格定义 `jielian-A2416A` 单可见光捷联式导引头的 Gazebo 基础模型、真值检测与单目标跟踪、二进制通信、H.264 视频、地面站及火箭穿越机装配接口。

捷联式导引头与载机刚性连接，不含机械框架、伺服关节或稳定平台。目标相对固定光轴的视线偏差直接作为俯仰和偏航失调角；平台框架角、陀螺角速度、视线角速度、导引头姿态及平台专有状态均不适用。

光学数据来自《单可见光跟踪模块产品规格书 V1.0-20261027》，报文定义来自《捷联导引头标准通信协议-20260813》，外形参考《导引头外形+组装示意图》。通信协议同时覆盖平台式产品，本模型只实现本规格列出的捷联适用字段和命令。

## 3. 真值检测与跟踪

### 3.1 坐标与投影

- 图像原点在左上角，`X` 向右，`Y` 向下。
- 从配置指定的 Gazebo 飞机实体读取真实世界位姿和包围盒，把包围盒八个角投影到相机平面并裁剪成检测框。
- 目标中心必须位于视野内；不计算地形、载机或其他实体遮挡。
- 目标在图像右侧时偏航失调角为正，目标在图像上方时俯仰失调角为正。
- 失调角限制为 ±20°，二进制遥测使用 `S16 ×100`。
- 有球面坐标参考时将目标真值位置转换为 WGS84；无地理参考时经纬高输出零并给出诊断状态。

### 3.2 状态与目标选择

- 真值检测与跟踪计算频率为 50 Hz，最多保留四个飞机目标，目标类型固定为协议值 4。
- 自动检测和自动锁定距离上限为 780 m；人工点选和框选距离上限为 1200 m。
- 未锁定时按检测框中心到图像中心的欧氏距离排序，同距按实体名排序。
- 自动锁定选择最靠近图像中心的有效目标；人工锁定后不自动切换实体。
- 锁定目标固定占目标槽 1，其余有效检测占槽 2～4；未锁定时四个槽均按中心距离排序。
- 已锁定目标暂时无效时进入 `TEMP_LOST`，保持原实体 2.5 s；期间恢复可见则继续跟踪，超时进入 `LOST`。
- 关闭自动锁定、取消跟踪或通信会话超时时立即结束相应跟踪状态。

### 3.3 光标、波门与显示约定

- 光标移动参数范围为 ±100，对应最大 400 px/s；停止命令或 0.5 s 未续发时速度归零。
- 跟踪修正量按像素一次性累加到瞄准点，并限制在当前目标投影框内。
- 波门放大或缩小使用 1.1 倍步进，比例限制为 0.5～4.0。
- 数字变倍为 1×、2×、4×循环；相机内参不变，显示坐标映射回 1920×1080 原图。
- 图像增强使用 Y 通道 CLAHE，`clipLimit=2.0`、网格 `8×8`。
- 完整 OSD 显示光标、检测框、跟踪框和状态文字；半消隐只显示光标和当前跟踪框；全消隐不叠加 OSD。

## 4. 二进制协议

### 4.1 帧格式与仿真传输

- 控制帧固定 45 字节，帧头字节依次为 `AA 55`，长度字段为 `0x2D`。
- 遥测帧固定 104 字节，帧头字节依次为 `55 AA`，长度字段为 `0x68`。
- 多字节数值均为小端；校验为协议规定范围内所有字节求和的低 8 位。
- 仿真扩展使用 UDP，每个数据报只承载一个完整二进制帧，默认共享端口 8001。
- 网关把遥测返回到最近一个有效控制帧的源地址。地面站以 10 Hz 发送 `0x00` 心跳，2 s 无有效控制帧时会话失效并停止识别和跟踪。
- 离散命令连续发送三帧，网关在 200 ms 内去重；心跳和连续光标移动不去重。
- 遥测频率为 100 Hz。检测测量为 50 Hz，因此相邻遥测帧可引用同一测量序号，但设备时标和报文序号必须更新。

### 4.2 支持命令

| 命令 | 行为 |
| --- | --- |
| `0x00` | 心跳/无操作 |
| `0x11` | 参数 1 除以 100 得到 0～8 Mbps；零恢复默认 2 Mbps |
| `0xB1` | 捷联光标速度，不驱动机械框架 |
| `0xB2` | 跟踪瞄准点像素修正 |
| `0xB3/0xB4` | 波门放大/缩小 |
| `0xB7` | 指定像素点锁定 |
| `0xB8` | 指定 ROI 锁定；选择相交面积最大的目标，无相交则失败 |
| `0xE8` | 当前光标位置锁定 |
| `0x8E` | 取消跟踪 |
| `0xB9/0x9B` | 数字变倍增加/减小 |
| `0x3F/0xF3` | 开启/关闭识别；关闭时清空检测和自动锁定，人工跟踪可继续 |
| `0x5F/0xF5` | 开启/关闭自动锁定；关闭后解除自动目标 |
| `0x6F/0xF6` | 开启/关闭图像增强 |
| `0x8F` | 更新遥测逻辑 IP `192.168.X1.X2`，不修改宿主机网卡 |
| `0x10/0x01` | 关闭/开启视频推流 |
| `0x15/0x16/0x17` | 完整 OSD/半消隐/全消隐 |

点坐标限制为 `X=0..1919`、`Y=0..1079`。多个目标检测框包含同一点时选择中心距离最小者。平台式、红外、激光及协议中未定义语义的命令必须拒绝并记录原因，不得静默成功。

### 4.3 遥测有效性

固定 104 字节布局保持兼容。框架角、平台陀螺角速度、视线角速度、导引头姿态及平台/伺服专有状态填零；自检、通用工作状态、波门、俯仰/偏航失调角、置信度、四个目标槽、变倍、识别模式、目标类型、载机姿态、逻辑 IP 和设备时标有效。无激光字段填零。

## 5. 视频与地面站

- 视频只提供 H.264/AVC，1920×1080@25 Hz，默认 2 Mbps；RTSP 地址为 `rtsp://127.0.0.1:8554/jielian_a2416a`。
- 编码输入使用 NV12，输出使用 High profile、byte-stream、无 B 帧、25 帧 GOP 的低延迟 CBR 流；RTP payload type 为 96，RTSP 使用 TCP 拉流。
- 不实现视频 SEI 或 UDP 裸码流。
- 编码和解码必须使用 NVIDIA NVENC/NVDEC；启动前检查可加载的 H.264 编码器和 `nvh264dec`，不提供软件回退。
- RTSP 服务启动即绑定逐机 RTP 端口，通过 `shmsink/shmsrc` 保持单一共享媒体源；首个客户端和断线重连不得改变编码器生命周期或造成 RTP 包级丢弃。
- 缺少 NVIDIA 驱动或 NVCODEC 能力时，视频服务和地面站必须输出明确诊断并退出视频链路，不能悄然切换软件编解码。
- 地面站提供视频、识别、自动锁定、点选、框选、取消跟踪、变倍、增强和 OSD 控制，不显示或控制云台角度、角速度。
- 点击窗口右上角关闭按钮、按 `Q` 或按 `Esc` 必须正常退出当前地面站实例，并释放视频、遥测、控制心跳和 JSON 转发资源；窗口关闭后不得由显示循环重新创建。
- 地面站按配置绝对路径登记独立进程并限制同一配置只运行一个实例。`ground_station/stop.sh` 无参数时停止当前用户的全部 A2416A 地面站，`--config` 只停止指定绝对配置实例，`--dry-run` 只预览。停止前必须核对用户、PID启动时间、解释器、模块、工作目录和配置身份；只停止地面站进程，不停止 Gazebo、PX4、网关、RTSP 或其他模型地面站。
- 地面站使用“发送艾晟报文”按钮启用转发，启用后按钮文字改为“停止发送”。面板中的目标 IP 和 Port 可编辑，默认值由 INI `[forward]` 提供，默认端点为 `127.0.0.1:9000`；`--forward-host` 和 `--forward-port` 可逐实例覆盖默认值。点击发送前必须校验 IP 和端口。
- 每收到一个有效 100 Hz 遥测帧，就发送一份 `aisheng_udp_bridge` 可直接接收的顶层 37 字段 JSON。字段集合严格为 `DytAishengTelemetry` 中标准 104 字节遥测可提供的字段，不发送帧头、原始字节、校验诊断、接收序号、测量序号或其他未知字段；四目标数组及经纬度原始整数保持艾晟桥契约。标准帧没有 `los_omega_n/e/d`，因此不发送这三个字段，由艾晟桥按既有兼容约定处理。

## 6. 火箭装配

- 独立装配模型名为 `rocket_jielian_a2416a`，PX4 airframe 编号为 4026，默认话题前缀为 `/rocket_jielian_a2416a`。
- 导引头替换火箭顶部 60 mm 外形，装配总长保持 590 mm，最高点保持 `z=+0.380 m`，导引头安装基面为 `z=+0.320 m`。
- 保留原火箭机质量和惯量近似，另增加 0.05 kg 导引头固定 link；装配总质量约 4.81 kg。
- 导引头通过固定关节连接到 `base_link`，不存在活动云台关节。
- 动力、电机、气动和原生传感器继承火箭基础模型；悬停推力、名义重心及 PX4 位置参考按装配质量重新派生。

### 6.1 PX4 02 场景集成

- 场景使用 `--aircraft-model rocket_jielian_a2416a` 显式选择装配，仅允许 `sim_truth` 跟踪后端；逐机话题前缀为 `/uav_<id>/pod`。
- 逐机控制/二进制遥测端口为 `8001 + id - 1`，艾晟兼容 JSON 送飞控端口为 `9000 + id - 1`，本机 RTP 端口为 `7001 + id - 1`，RTSP 端口为 `8554 + id - 1`，路径为 `/jielian_a2416a`。
- 每个实例生成运行期地面站 INI；地面站由操作者点击“发送艾晟报文”后才向飞控端口转发。飞控复用现有 `aisheng_udp_bridge` 发布 `dyt_aisheng_telemetry`，不新增重复桥接模块。
- 真值目标集合包含全部 A2416A 场景飞机以及实体 `xiaomotuo`、`xiaobianfu`。A2416A 组合飞机加入 02 场景雷达航迹，按小型飞机 3 km 标称距离处理。
- `stop.sh` 清理场景启动的 A2416A 网关、RTSP、PX4、Gazebo 和辅助进程，不修改资产仓基础文件。

## 7. 验收准则

- 配置、SDF 生成和装配生成必须可重复，且不得修改任何基础输入资产。
- SDF 校验通过；基础导引头没有 joint，动态装配只增加一个固定安装 joint。
- 自动测试覆盖协议黄金帧、校验、错误帧、命令去重、会话切换、2 s 超时和拒绝命令。
- 地面站生命周期测试覆盖关闭按钮不重建窗口、多配置实例隔离、定向停止、全部停止、仅预览、PID复用防护、错误身份拒绝以及升级前实例兼容停止。
- 投影测试覆盖视场边界、四象限符号、±20°限制、780/1200 m边界、四目标排序、人工不换目标和 2.5 s 重捕获。
- 频率验收覆盖图像 25 Hz、测量 50 Hz、二进制遥测与艾晟 JSON 转发 100 Hz；相邻帧复用同一 50 Hz 测量时仍逐帧发送。
- 视频验收覆盖硬件预检、H.264 RTSP、High profile、分辨率、25 Hz稳态帧率、码率、首次连接、断线重连、启停、OSD和增强；硬件环境不满足时记为前置条件失败。
- 近景世界保存无碰撞定位标志 `JIELIAN_A2416A_LOCATION_MARKER`，浏览相机近裁剪 0.005 m、建议灵敏度 0.1。
- 火箭动态验收覆盖 30 s 悬停、200 km/h 持续 30 s、300 km/h 持续 10 s、降落停机及飞行中的真值跟踪与遥测链路。
