# 两轴吊舱验证

## 环境与范围

使用 Gazebo Harmonic（Sim 8、Transport 13、Msgs 10）、OpenCV C++/Python、GStreamer NVIDIA NVENC/NVDEC。基础模型采用立装，pitch 轴为随动 −Y，范围 −90°～+45°，0° 朝天、−90° 朝前；当前两轴控制/遥测协议为 5。Python 网关和 Linux Station 共用可重建的仓库根目录 `.venv-linux`，虚拟环境不入库。

独立地理部件验收使用分区 `two_axis_forward_acceptance`、UDP 18766、RTSP 18555，不加载载机或 PX4。实际端点验证使用独立小型演示分区 `two_axis_pitch_v5_validation`，测试后关闭该临时服务。

## 离线验证

- 4 项基础模型测试通过：工程尺寸、底环水平方向、91 mm 外廓、SDF 关节轴 −Y、光学姿态、负俯仰朝前与生成一致性。
- CTest 1/1 通过：`Rz(yaw) Ry(-pitch)`、正负俯仰和零位的有限差分 Jacobian、朝天退化、动态安装前馈、速度/加速度、前瞻限位、回零、故障、CSRT、遮挡和断帧保护。
- 112 项 Station/网关测试通过：INI 配置、JSON 配置拒绝、协议 5 门禁、身份与来源过滤、两轴控制、互斥视觉模式、人工抢占、可靠回执、摇杆释放与焦点保护、Linux NVDEC、Windows D3D11 参数及拒绝软件回退；艾晟测试覆盖 off/detect/搜索与残留 TRACK 矛盾时清零、网关重启后的跟踪停止同步、重复 off 与人工/回零隔离、仅九字段、倍率、无效清零、非法值拒绝、停止/重启、发送中编辑自动暂停且重启后仅发往新端口、地址保存与输入焦点。
- 16 项视觉核心/环境测试通过：YOLO11 输出、NMS、连续命中确认、ByteTrack 两阶段关联、Kalman/Hungarian、稳定编号、中心最近选择、红框及归档 ONNX 实际加载。
- 590 mm 装配和火箭场景 61 项离线测试通过（35 项装配、26 项场景）；动态装配结构、5.00 kg质量、惯量、固定名义重心/CA/EKF派生、源资产继承和可重复生成检查通过。基础火箭机51项及速度场景15项离线回归同时通过，基础机几何、参数和原始飞行记录未改动。
- 2 项地理部件初始化测试通过：移动靶初始完整位姿与源模型一致，Gazebo 复位指令保留源朝向。

## 艾晟报文与脱靶量

Linux 实窗自测实际编辑回环 IP/端口，点击发送、停止和重启；自测接收端为 `127.0.0.1:19001`，不覆盖用户保存的实际目标地址。输入、停止/重启、朝前角度为负和脱靶量换算已通过实窗验证。当前九字段转换另外使用真实网关遥测与本机临时 UDP 接收端验证：连续 10 包均只含规定字段，`target_confidence` 均为浮点数 80.0。112 项回归测试同时覆盖有效/丢失时该常量不变、不缩放，不使用输入报文中的同名值。

例如实际输出 pitch −5627.3 对应 −56.273°，垂直脱靶 −1.72 对应 −0.0172°；没有第二次反转机械俯仰符号。停止跟踪后原始 `target.miss.valid=false` 且数值/帧号为 null，艾晟状态、`tracking_confidence` 和脱靶角归零，`target_confidence` 仍固定为 80.0，机械角和机械角速度保留当前测量。

报告及截图：`runs/two_axis_forward_acceptance/aisheng_v5_check/`。Linux 使用 NVENC/NVDEC；Windows 共用转换、输入和显示代码，实际 D3D11 窗口及显卡驱动仍需 Windows 机器验收。艾晟置信度 255/0 仅表示约定的跟踪有效性，连续质量评分尚未实现，见[评估](tracking-quality-assessment.md)。

网关 `status_udp.json` 仍独立输出完整遥测，不采用 Station 的艾晟转换。配置读取、20 Hz 独立发送、原 Station 50 Hz 会话、过期暂停、发送异常和关闭后原会话继续工作均由本机真实 UDP 测试覆盖。

状态同步的真实网关/回环 UDP 检查覆盖八种情况：启动清除遗留 TRACK、重复关闭视觉、仅检测、自动搜索、自动锁定有效、等待手动框选、手动框选有效、退出跟踪。只有两种有效跟踪输出 `track_status=1`、`tracking_confidence=255.0`，其余输出 `0/0.0`；所有情况 `target_confidence=80.0`。启动时同时确认插件实际回到 IDLE，不仅检查转换值。

## 限制

固定安装部件检查不代替载机飞行验收；火箭机载场景已同步角定义并通过离线检查，协议 5 的完整飞行与动态跟踪仍待该场景单独复测。两轴没有第三轴画面水平稳定；零位朝天存在偏航视线退化。外廓、孔位、碰撞、质量和惯量为仿真近似，未经实物标定；检测未覆盖所有真实飞机、高速运动和光照条件。

视频要求 NVIDIA 硬编解码，不提供软件回退。当前宿主 GPU 为 RTX 4060，驱动 595.99.02；生产使用 `nvcudah264enc` 与 `nvh264dec`。硬件验证须在可访问 NVIDIA 设备的宿主环境执行，沙箱设备不可见不代表驱动故障。
