# 前视安装、坐标与人工观察

模型在整机层施加一次绕 Y 轴 +90° 的安装姿态，即 RPY `(0, π/2, 0)`。内部几何、关节轴和相机相对姿态保持复制运动链。默认机械角 `(yaw,pitch)=(0,0)` 时光轴朝安装后的前方；演示世界用同样的 Y90 姿态替换模型位置，不再次叠加 Y90。

`model.sdf` 已保存该整机姿态。装配若覆写整机 `pose`，应显式保留所需前视朝向；不能在已有姿态上再重复安装旋转。相机传感器内部的 RPY `(0,−π/2,0)` 用于传感器坐标与原几何对齐，不是第二次整机安装变换。

| 量 | 复制运动链局部约定 | 默认前视安装下的含义 |
| --- | --- | --- |
| 外轴 yaw | 转轴 `+X` | 正值向右，负值向左 |
| 内轴 pitch | 转轴 `−Y`，随外轴运动 | 正值向上，负值向下 |
| 零位光轴 | 安装局部 `+Z` | 前视方向 `+X` |
| 原图像素 | X 向右、Y 向下 | 指点命令以图像中心为零，和机械 pitch 正号不同 |
| 目标角偏差 | 水平右正、垂直上正 | 从当前相机内参换算，垂直像素符号转换一次 |

两轴机械范围默认 yaw −90°～+90°、pitch −90°～+30°。俯仰接近 −90° 时存在真实视线退化：外轴仍可机械转动，但其运动对当前视线方向的作用退化；诊断显示 `singular`，控制输出必须保持有限。组件没有独立横滚框架自由度。

## 演示定位

使用 `bash scripts/run_demo.sh --session demo --gui` 打开浏览窗口。默认部件底座原点在世界 `(0,0,1.5) m`，预设近景浏览相机位姿为 `(0.55,−0.45,1.65,0,0.2,2.4)`，位置单位 m、姿态单位 rad。

在实体树中搜索模型 `zhongke_d80` 或橙色标志 `ZHONGKE_D80_LOCATION_MARKER`。标志箭杆视觉中心在 `(−0.04,−0.26,1.52) m`，箭头位于 `(−0.04,−0.10,1.52) m`，指向云台侧方；标志和支架仅作定位显示，标志不设置碰撞体。默认目标实体为 `target_a`、`target_b`、`target_c`，位于前方约 50 m，横向分布在窄视场内。

演示生成配置保存了标志和默认近景；重新启动浏览窗口可恢复该近景。不要用临时世界插入物代替保存的定位标志。

## 近景浏览

`viewer.near_clip_m` 默认 0.005 m，是浏览相机近裁剪；`optics.near_clip_m` 是吊舱视频相机近裁剪，两者分别配置。前者写入演示 GUI 场景，修改后重新生成并重启该 GUI；后者参与视频相机成像，重启组件生效。

Gazebo 滚轮缩放以鼠标指向的三维位置为参考；指向远处背景会使一步缩放跨过小部件。近景时将鼠标放在部件实体表面，再用右键缓慢拖动微调。浏览灵敏度默认值为 0.1，同时影响缩放、平移和旋转，可以按场景尺度调整。

若需要手动应用灵敏度，先从 `runs/demo/session.ini` 读取本次 `gz_partition`，在同一分区、GUI 已启动时执行：

```bash
GZ_PARTITION=替换为本次清单值 gz service \
  -s /gui/camera/view_control/sensitivity \
  --reqtype gz.msgs.Double --reptype gz.msgs.Boolean \
  --timeout 3000 --req 'data: 0.1'
```

成功响应为 `data: true`。无 GUI 的 `--headless` 模式没有该浏览服务；调浏览灵敏度不会改变吊舱视频视场、焦距或物理跟踪结果。
