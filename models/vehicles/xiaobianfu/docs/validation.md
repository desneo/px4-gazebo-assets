# 小蝙蝠验证

当前模型已由用户在Gazebo中确认外形；确认记录见 [appearance.json](appearance.json)。当前配置完成PX4/Gazebo完整自动飞行验收，未发生失控或failsafe。

| 项目 | 当前结果 |
| --- | --- |
| 整机视觉长度 / 翼展 | 0.400 m / 1.000 m（含尾桨） |
| 总起飞质量 | 1.000 kg |
| 自动起飞 | 手抛脉冲触发PX4发射检测，自动爬升至巡航高度 |
| 满油门持续平飞 | 30.006 连续仿真秒 |
| 平飞真值速度 | 100.97～101.62 km/h |
| 真值高度最大偏差 | 1.990 m（相对50m目标） |
| 接地前下降速度 | 0.822 m/s |
| 接地前bank / pitch | 0.008° / +4.264° |
| 草地机腹着陆 | 自动任务进近、正常姿态接地，真实滑行停止 |
| 停机与稳定 | 自动解除武装后，真值速度低于0.3m/s且正常姿态连续3.006s |

目标速度为100km/h，最大满油门速度的仿真验收范围为目标至目标的102%。测试在无风、恒满电条件下进行；控制器使用Gazebo真值高度作验收外环，PX4完成姿态闭环、起飞和任务着陆。气动、动力、惯量与草地摩擦为仿真估计，有限时间试验不能证明真实飞机的无限续航或真实性能。
