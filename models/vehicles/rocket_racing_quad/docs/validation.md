## 当前模型与适用边界

原生 SDF 的机身总高0.590 m，对角电机轴距约0.590010 m，桨径0.254 m，动力舱长度0.090 m、直径0.080 m；机身质量7.44 kg、整机质量7.70 kg，机身重心 z=-0.094 m，使用显式惯性矩和1570 rad/s最大转速。PX4电机位置、反扭矩系数及转速上限与SDF配套；`MPC_THR_HOVER=0.0755504`用于本次通过的配置，7.70 kg静态理论值约0.0727901。

全部网格及碰撞体的轴向包络为 z=-0.225～+0.365 m，机身几何轴向中点和碰撞圆柱中心为 z=+0.070 m，`base_link` 原点为 z=0。测试世界初始原点离地0.230 m，机尾离地0.005 m、顶部离地0.595 m。显示翼面与动力舱连续连接；机臂碰撞体保留较短近似，当前不考察连接处接触精度。

质量、重心、惯性、动力和气动是独立配置，不由几何外形自动推算。当前结果只支持上述简化仿真和无风直线飞行条件，不代表真实硬件性能，也不覆盖风场、任意航迹、连接处碰撞精度或机载视频/跟踪。7.94 kg顶部两轴吊舱组合另有[独立完整通过记录](../../../../assembledmodels/rocket_two_axis_pod/docs/validation.md)，单机与组合体结果分别对应各自运行资产。

## 复测入口

```sh
sh models/vehicles/rocket_racing_quad/tests/run_check.sh headless
# 替换为启动器输出的实际报告路径

```
